## Authority and maintenance

- `../BACKLOG.md` is the only current completion backlog.
- `BACKLOG.md` in this directory is historical story evidence.
- Date-stamped product and architecture reviews are snapshots, not current status sources.
- API paths and schemas are generated by FastAPI at `/openapi.json` and `/docs`.
- Scanner availability is determined at runtime by the capability catalog,
  worker heartbeats, and Operations. A catalog entry does not prove a worker
  has the binary.
- Documentation changes are required when routes, migrations, queues, scan
  profiles, security boundaries, environment variables, or supported tools change.

## Capability labels

- **Operational:** connected UI/API workflow with persistence and failure states.
- **Partial:** useful implementation exists but important workflow or assurance remains unfinished.
- **Conditional:** requires an external account, credential, binary, service, or isolated environment.
- **Reference-only:** practitioner content that does not launch a scan.
- **Planned:** backlog item without a production workflow.
